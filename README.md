# arnaudligny.fr

Source of [arnaudligny.fr](https://arnaudligny.fr), a personal website (CV, blog, projects and talks) generated by [Cecil](https://cecil.app), automatically built and deployed with [Netlify](https://www.netlify.com).

[![Netlify Status](https://api.netlify.com/api/v1/badges/5df6352b-ec80-455f-a6d8-059c176675c4/deploy-status)](https://app.netlify.com/sites/arnaudligny/deploys)
[![Integration tests](https://github.com/ArnaudLigny/arnaudligny.fr/actions/workflows/integration-tests.yml/badge.svg)](https://github.com/ArnaudLigny/arnaudligny.fr/actions/workflows/integration-tests.yml)

## Requirements

- [PHP](https://www.php.net) 8.3+ (required by Cecil 9), with the `mbstring`, `fileinfo`, `gd`, `intl` and `gettext` extensions
- [Composer](https://getcomposer.org) (to install themes)
- [Node.js](https://nodejs.org) 22+ (to run the tests)

## Project structure

| Path            | Description                                                              |
| --------------- | ------------------------------------------------------------------------ |
| `cecil.yml`     | Main Cecil configuration (menus, taxonomies, themes, DevSpace settings…)  |
| `config/`       | Configuration overrides (e.g. `dev.yml`)                                  |
| `pages/`        | Markdown content: `index.md`, `cv.md`, `a-propos.md`, `blog/`, `projets/`, `talks/` |
| `layouts/`      | Twig templates overriding the theme                                       |
| `themes/`       | Themes: `devspace`, `pwa`, `headers`, `redirects` (installed by Composer), and the legacy `ali1` |
| `assets/`       | Images, videos and CSS sources (`tailwind.css` → `styles.css`)            |
| `static/`       | Files copied as-is to the root of the site (PDF résumés, `favicon.ico`…)  |
| `models/`       | Front matter templates used by `cecil new:page`, one per section (`blog.md`)|
| `scripts/`      | Build and deploy helper scripts                                           |
| `tests/e2e/`    | Playwright navigation tests                                               |
| `_site/`        | Generated site (not versioned)                                            |

## Install

Themes are installed as Composer dependencies:

```bash
curl -SOL https://cecil.app/cecil.phar
composer install
```

## Build and serve locally

```bash
php cecil.phar serve
```

Open <http://localhost:8000>

Serve without service worker nor images optimizations (faster):

```bash
php cecil.phar serve --config=config/dev.yml
# or
npm run serve
```

Build only:

```bash
php cecil.phar build -v
```

> Shortcuts are available for macOS (`build.command`, `preview.command`, `edit.command`) and Windows (`build.cmd`, `preview.cmd`, `edit.cmd`).

## Build CSS (Tailwind)

Styles are built from `assets/tailwind.css` to `assets/styles.css` with [tailwind-builder](https://github.com/ArnaudLigny/tailwind-builder):

```bash
composer css:build   # one-shot, minified
composer css:watch   # watch mode
```

## Serve locally with Netlify CLI

### Setup Netlify CLI

```bash
npm install netlify-cli -g
netlify link
```

### Run local server

```bash
php cecil.phar serve & netlify dev
```

Open <http://localhost:8888>

## Tests

Navigation tests are written with [Playwright](https://playwright.dev) and live in [`tests/e2e`](tests/e2e).

```bash
npm install
npx playwright install
npm test          # starts the local server, then runs the tests
npm run test:ui   # interactive mode
```

They also run on GitHub Actions on every push to `master` touching `layouts/` or `assets/`, see [`.github/workflows/integration-tests.yml`](.github/workflows/integration-tests.yml).

## HTML code analysis

Configured through [`.htmlvalidate.json`](.htmlvalidate.json):

```bash
npm install html-validate -g
html-validate _site
```

## Deploy

Production deployment is handled automatically by Netlify (see [`netlify.toml`](netlify.toml)) on every push to `master`.

Manually, with the Netlify CLI:

```bash
cd _site
npm install netlify-cli -g
netlify init
netlify deploy
```

Configurations for alternative hosts are also provided: [`vercel.json`](vercel.json), [`render.yaml`](render.yaml) and [`statichost.yml`](statichost.yml). See [`scripts/README.md`](scripts/README.md) for other deployment options (GitHub Pages, Cloudflare cache purge).
