Package Composer qui compile du CSS via le binaire standalone de [Tailwind CSS](https://tailwindcss.com), avec téléchargement automatique, cache local et vérification d’intégrité (SHA-256).

Le projet peut être utilisé en local (`vendor/bin/tailwind-builder`), installé globalement, ou intégré dans une CI via une action GitHub (`ArnaudLigny/tailwind-builder`).
